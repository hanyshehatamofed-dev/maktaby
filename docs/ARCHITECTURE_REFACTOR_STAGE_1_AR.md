# مكتبي PRO — إعادة الهيكلة الهندسية (المرحلة الأولى)

## ما تم في هذه الدفعة

- توحيد أسماء ملفات المصدر داخل `src/js/` و`src/css/` وإزالة أرقام الإصدارات والبصمات اليدوية من أسمائها.
- إضافة خريطة أصول عبر `import.meta.glob(..., { query: '?url' })`؛ لذلك يظل تحميل ملفات JavaScript الكلاسيكية متوافقًا مع اعتماد التطبيق الحالي على `window` وواجهات `onclick`، بينما يولّد Vite أسماء إنتاج ذات بصمات تلقائية.
- جعل `vite-plugin` محليًا داخل `vite.config.js` يولّد `dist/sw.js` بمعرّف بناء محسوب من قائمة ملفات البناء، ويولّد قائمة Precache من أسماء ملفات الإنتاج ذات البصمات.
- نقل `manifest.json` و`_headers` و`_redirects` إلى `public/` كي تنسخها Vite إلى جذر `dist/`.
- فصل الاختبارات في `tests/` والتوثيق في `docs/`.
- إضافة بوابة أمان لتسجيل الخروج: تمنع الخروج والتنظيف عند وجود عمليات مصروفات أو مزامنة حالة معلقة. بعد التأكد من خلو قوائم الانتظار، تنظف نسخة الحالة المحلية وقاعدة IndexedDB وكاش التطبيق.
- الإبقاء على الإصدار `10.9.1`؛ هذه تغييرات صيانة وبنية داخلية.

## ما لم يكتمل بعد

- لم يتم بعد تقليص `renderer.js` إلى 80–120 كيلوبايت. ما زالت كتلة كبيرة من منطق الشاشات مترابطة عبر متغيرات ودوال داخل نطاقات JavaScript مشتركة؛ نقلها دفعة واحدة قد يكسر الصلاحيات والحفظ والأرشفة. يلزم فصلها تدريجيًا بواجهات واضحة واختبارات تكامل.
- لم يتم بعد نقل العرض الكامل للنظرة الأسبوعية وواجهة أرشيف المهام إلى وحدات مستقلة. توجد وحدات lazy-load سابقة للأدوات المنفصلة، لكن ذلك لا يحقق هدف تقسيم النواة بالكامل.
- لم يتم تفعيل تشفير IndexedDB بعد. بصمة SHA-256 الحالية للتحقق من سلامة نسخة الاسترداد وليست تشفيرًا. يتطلب التشفير تصميم دورة مفاتيح مرتبطة بجلسة Supabase ومعالجة تدوير رموز الدخول، ونسخ البيانات القديمة، والاسترداد دون فقد عمليات معلقة. لا ينبغي ادعاء حماية تشفيرية قبل تنفيذ هذا الانتقال واختباره.
- لم يتم تنفيذ اختبار متصفح فعلي أو اختبار متعدد المستخدمين/اتصال Supabase حي في هذه البيئة.

## البناء والتحقق

من جذر المشروع:

```bash
npm install
npm run build
npm run qa
```

اختبارات `npm run qa` الحالية اختبارات ثابتة/منطقية محلية، ولا تغني عن اختبار بناء Vite أو اختبار تشغيل التطبيق على بيئة النشر وقاعدة البيانات الحية.
