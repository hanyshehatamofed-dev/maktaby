# سجل تغييرات — المرحلة الثانية

- إضافة `maktaby-crm.js` كحزمة تحميل كسول.
- إضافة `maktaby-achievements.js` لتقارير وإنجازات الموظفين كحزمة تحميل كسول.
- إزالة كود الوحدتين من `renderer.js` وربط التحميل عند اختيار القسم.
- منع جلب بيانات CRM الكاملة عند بداية التطبيق قبل فتح القسم.
- عدم إضافة وحدات CRM والتقارير إلى قائمة precache الأساسية.
- إضافة `QA_LAZY_BUSINESS_FEATURES_10_9_1.cjs` وإدراجه ضمن `npm run qa`.
- لا تغييرات على قاعدة البيانات أو إصدار المنتج.
- لم يتم إنتاج `dist` في بيئة التنفيذ لعدم توفر Vite محليًا.
