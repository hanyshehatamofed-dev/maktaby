# سجل التغييرات — MAKTABY PRO 10.9.1

## Refactor Stage 1

- أسماء ملفات المصدر أصبحت ثابتة ونظيفة.
- ملفات الإنتاج تُطلب عبر عناوين Vite ذات البصمات التلقائية.
- Service Worker يُولّد وقت البناء بمعرّف تلقائي وقائمة Precache للأصول الأساسية.
- ملفات الاستضافة العامة انتقلت إلى `public/`.
- التوثيق والاختبارات انفصلا عن مجلد المصدر.
- تسجيل الخروج أصبح يتحقق من قوائم الانتظار قبل حذف التخزين المحلي؛ العمليات غير المتزامنة تمنع الحذف والخروج.

لم يتغير رقم الإصدار الوظيفي. هذه الدفعة لا تتضمن بعد تشفير IndexedDB أو التفكيك الكامل لملف `renderer.js`.
