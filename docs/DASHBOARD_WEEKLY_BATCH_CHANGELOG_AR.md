# MAKTABY PRO 10.9.1 — دفعة تطوير لوحة القيادة الأسبوعية

## التغييرات المرئية للمستخدم
- إضافة قسم «نظرة الأسبوع» في الصفحة الرئيسية يعرض الأيام السبعة القادمة.
- عرض عدد الجلسات والمهام المفتوحة لكل يوم، مع تمييز اليوم الحالي.
- إضافة إجمالي جلسات الأيام السبعة في رأس القسم.
- جعل مؤشر الاتصال في مركز القيادة يعكس حالة اتصال المتصفح الفعلية، ويتحدث فور حدوث online/offline.
- تصحيح عداد «جلسة قادمة» ليحسب كل الجلسات القادمة، بدلاً من الاقتصار على أول أربع جلسات المعروضة.
- تحسين عرض نظرة الأسبوع على الشاشات الصغيرة.

## حدود التغيير والسلامة
- لم تتغير جداول Supabase أو بيانات العملاء أو القضايا أو الحسابات.
- لم تتغير صلاحيات المستخدمين أو مسارات الحفظ والمزامنة.
- لا يدّعي مؤشر الشبكة نجاح اتصال Supabase؛ إنه يعرض حالة اتصال الإنترنت لدى المتصفح فقط.
- رقم الإصدار ثابت 10.9.1 لأن هذه دفعة تحسين واجهة وصيانة.
- تحديث معرف البناء واسم Cache حتى لا يحتفظ المتصفح بالواجهة السابقة.
