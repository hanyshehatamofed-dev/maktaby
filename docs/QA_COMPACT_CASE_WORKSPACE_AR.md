# تقرير فحص MAKTABY PRO 10.9.1 — واجهة القضايا والجلسات المضغوطة

## نطاق التعديل
- إعادة تنظيم صفحة القضايا والجلسات لتظهر في لوحة واحدة مضغوطة.
- استبدال الجدول العريض ذي 14 عمودًا بجدول مختصر: الموكل/الخصم، رقم الدعوى، الموضوع، المحكمة/الدائرة، تاريخ الجلسة، الرول، الحالة، عرض.
- ترتيب الجلسات التي تحتاج قرارًا أولًا تلقائيًا.
- إضافة مؤشرات موجزة: إجمالي القضايا، المتأخرة، المطلوب قرارها، والقادمة.
- فتح تفاصيل القضية المختارة أسفل الجدول مع حقول الرول والقرار وسبب التأجيل وتاريخ الجلسة الجديدة.
- إبقاء الخط الزمني، سجل الجلسات، المحررات والإعلانات، واتساب الموكل، تعديل القضية، والأرشفة.
- إضافة responsive layout وتقليل المسافات على الشاشات القصيرة.

## الثوابت
- الإصدار باقٍ 10.9.1؛ التعديل واجهة وصيانة فقط.
- Web Only؛ لا توجد حزمة Windows.
- لا تغييرات SQL أو Supabase schema أو RLS أو بيانات.
- لم يتم النشر إلى Cloudflare ولم يتم اختبار اتصال مباشر بقاعدة الإنتاج.
