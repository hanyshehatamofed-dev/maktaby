# تحديث واجهة المهام — MAKTABY PRO 10.9.1

## ما تغير
- إعادة تصميم صفحة المهام إلى مساحة عمل أكثر وضوحًا واحترافية.
- إضافة مؤشرات إجمالي المهام، وقيد التنفيذ، والمتأخرة، والمنجزة.
- إضافة شريط مرئي لمعدل الإنجاز.
- تنظيم المهام داخل مجلدات المحكمة مع عدادات لكل مجلد.
- تحسين البحث وعرض الأولوية والحالة والمسؤول وسجل التعديلات وتفاصيل الإنهاء.
- تحسين العرض على الشاشات الصغيرة.

## ما لم يتغير
- لم تتغير بنية البيانات أو أسماء الحقول أو جداول قاعدة البيانات.
- لم تتغير صلاحيات إنشاء/تعديل/إنهاء المهام أو مسار اعتماد الموظفين.
- لم تتغير آلية أرشفة المهام أو استعادتها.
- رقم الإصدار باقٍ 10.9.1 لأن التحديث واجهي/صيانة.
