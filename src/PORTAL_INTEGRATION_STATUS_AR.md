# حالة دمج بوابة متابعة الموكلين

تم دمج صفحة البوابة كمسار مستقل داخل حزمة الويب الحالية:
- `/track` و`/track.html` يفتحان صفحة متابعة الموكل.
- أضيفت ترويسات منع الفهرسة والتخزين المؤقت وإرسال Referer للمسار.
- لم تتغير ملفات المحرك الرئيسي أو جداول قاعدة البيانات أو صلاحيات Supabase أو RPC.

## حدود هذه الحزمة
هذه مرحلة دمج واجهة/مسار فقط وليست إطلاقاً آمناً للموكلين:
- رمز `123456` تجريبي ثابت، ولا يوجد إرسال SMS أو OTP حقيقي.
- بيانات العرض تجريبية وليست مرتبطة بقاعدة بيانات المكتب.
- لا يتم إنشاء token أو QR حقيقي ولا توجد إدارة روابط أو جلسات موكلين.
- لا تنشر هذا المسار للموكلين ولا تستخدمه مع بيانات حقيقية قبل استكمال الخادم وSQL وRLS ومزود SMS.

## المطلوب قبل الإنتاج
1. اعتماد SQL للجداول والسياسات بعد المراجعة.
2. Worker/Edge Function للتحقق من token وOTP وإصدار جلسة آمنة.
3. تكامل SMS مع مزود فعلي وأسرار محفوظة بالخادم.
4. API يعيد حقولاً مسموحاً بها فقط، مع اعتماد يدوي للأحداث والطلبات ومشاركة الحسابات.
5. اختبارات صلاحيات واختبارات إساءة الاستخدام ثم نشر تجريبي.
